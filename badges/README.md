# Move-a-thon theme badges

Drop each week's fixed award emblem here, named by theme id:

- `identity.png`  ← this week (Identity)
- future: `strength.png`, `clarity.png`, … (one per theme)

**Format:** PNG, **transparent background**, square (~1024×1024), the medal
filling ~80% of the frame, no text baked in (the card adds the wording).

Each file is referenced from `THEMES[n].badge` in `../index.html` and embedded
into the shareable certificate. Replacing a file here updates the badge with no
code change.
